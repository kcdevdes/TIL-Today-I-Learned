### Key Concepts
- **DTO / `record`**: immutable data carrier. 1 DB row = 1 `EquipmentResponse` = 1 JSON object.
- **DI**: `JdbcClient` is auto-configured; the repository receives it via constructor injection.
- **`RowMapper`**: converts one `ResultSet` row into one object. This is where `snake_case` → `camelCase` mapping happens by hand.
- **Type choices**
  - `TIMESTAMPTZ` → `OffsetDateTime` (keeps offset; `LocalDateTime` loses it). `getObject(..., OffsetDateTime.class)` returns `null` for NULL.
  - `rs.getLong()` returns `0` for NULL → OK for a PK, risky for nullable numbers.
  - `RunningStatus.valueOf()` throws on unknown values → **fail-fast** on bad data.
- No `SELECT *` (explicit contract); no `ORDER BY` = no guaranteed order.
- **Compile success ≠ working query.** Only running against the real DB checks column names, table existence, and enum conversion.
- `testImplementation` dependencies are visible only from `src/test` (kept out of the production jar).
